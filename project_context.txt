# Коллекция Полезных HTML-Сниппетов

Этот документ — наша "шпаргалка" для часто используемых HTML-конструкций.

## Ссылки на Мессенджеры и Социальные Сети

### Telegram
- **Прямой переход в приложение:** `<a href="tg://resolve?domain=USERNAME">Telegram</a>`
- **Веб-ссылка (откроется в браузере):** `<a href="https://t.me/USERNAME">Telegram</a>` (используем `t.me` как более короткий вариант)

### WhatsApp
- **Диалог (универсальная ссылка):** `<a href="https://wa.me/79991234567" target="_blank">WhatsApp</a>`
- **Диалог с готовым текстом:** `<a href="https://wa.me/79991234567?text=Добрый%20день!" target="_blank">WhatsApp с текстом</a>`
- **Старый формат (может не работать):** `<a href="whatsapp://send?phone=+79991234567">WhatsApp</a>`

### Viber
- **Чат (для ПК):** `<a href="viber://chat?number=+79991234567">Viber</a>`
- **Добавить контакт (для мобильных):** `<a href="viber://add?number=79991234567">Viber</a>`

### Skype
- **Начать чат:** `<a href="skype:ЛОГИН?chat">Skype Chat</a>`
- **Позвонить:** `<a href="skype:ЛОГИН?call">Skype Call</a>`

### VKontakte
- **Перейти к диалогу:** `<a href="https://vk.me/ID_ПОЛЬЗОВАТЕЛЯ">Vkontakte</a>`

### Facebook Messenger
- **Перейти к диалогу:** `<a href="https://www.messenger.com/t/USERNAME">Facebook Messenger</a>`

### Instagram
- **Ссылка на профиль:** `<a href="https://www.instagram.com/USERNAME" target="_blank">Instagram</a>`


## Специальные типы ссылок

### E-mail (Электронная почта)
- **Простая ссылка:** `<a href="mailto:name@example.com">Написать на E-mail</a>`
- **Ссылка с темой и текстом:** `<a href="mailto:name@example.com?subject=Тема%20письма&body=Здравствуйте!">E-mail с темой</a>`

### Телефон
- **Простая ссылка на звонок:** `<a href="tel:+79991234567">+7 (999) 123-45-67</a>` (номер лучше указывать в международном формате без лишних символов)

### Файлы
- **Открыть файл в новой вкладке:** `<a href="/path/to/file.pdf" target="_blank">Открыть документ</a>`
- **Скачать файл:** `<a href="/path/to/image.jpg" download>Скачать изображение</a>`
- **Скачать файл с новым именем:** `<a href="/path/to/image.jpg" download="my-cool-photo.jpg">Скачать с другим именем</a>`

# Vite Bridge Boilerplate: План и Архитектура (v3.13 - JS Завершен)

Этот документ (PLAN.md) является единственным источником правды для архитектуры и плана реализации проекта. Все действия выполняются в строгом соответствии с этим планом.

## 1. Ключевые особенности и философия

- **Монорепозиторий (Monorepo):** Весь проект, включая frontend и backend части, находится в едином Git-репозитории.
- **Разделение ответственности:** Проект имеет строгую двухкомпонентную структуру (`/frontend` и `/backend`).
- **Современная модульная архитектура SCSS:** Мы используем методологию ITCSS с директивами `@use` и `@forward`. Каждая папка в `scss` имеет "бочковой" файл (`_index.scss`), который собирает и экспортирует ее содержимое.
- **Безопасный и предсказуемый рабочий процесс:** Мы следуем четкой последовательности: Разработка -> Коммит -> Сборка -> Синхронизация.
- **Гибридный подход к качеству кода:** Используется Biome для быстрой проверки JS/CSS и Prettier для форматирования Nunjucks.
- **Продвинутый шаблонизатор:** Nunjucks с поддержкой Front Matter и глобальных файлов данных.
- **Профессиональная архитектура:** Файловая структура исходников и сборки четко организована.
- **Автоматическое управление путями:** `manifest.json` и PHP-функция `get_asset()` для версионирования ассетов.

6. Настройка Vite: Шаблонизатор и структура сборки
Настройка build.rollupOptions.output в vite.config.js:
code
JavaScript
// Внутри defineConfig
build: {
  outDir: 'dist',
  manifest: true,
  rollupOptions: {
    output: {
      entryFileNames: 'js/[name].[hash].js',
      chunkFileNames: 'js/chunk.[hash].js',
      assetFileNames: (assetInfo) => {
        const extType = (assetInfo.fileName || assetInfo.name).split(".").pop();
        if (/css/i.test(extType)) return "css/app.[hash].css";
        if (/png|jpe?g|svg|gif|tiff|bmp|ico|webp|avif/i.test(extType)) return "img/[name].[hash][extname]";
        if (/woff|woff2|eot|ttf|otf/i.test(extType)) return "fonts/[name].[hash][extname]";
        return "[name].[hash][extname]";
      },
      manualChunks(id) {
        if (id.includes('node_modules')) {
          return 'vendor';
        }
      },
    },
  },
},

PHP-функция get_asset в functions.php (WordPress):
code
PHP
<?php
function get_asset($entry) {
    static $manifest = null;
    $manifestPath = get_template_directory() . '/assets/manifest.json';

    if ($manifest === null) {
        if (!file_exists($manifestPath)) {
            $dev_server_url = 'http://localhost:5173';
            return $dev_server_url . '/frontend/src/' . $entry;
        }
        $manifest = json_decode(file_get_contents($manifestPath), true);
    }

    if (isset($manifest[$entry]['file'])) {
        return get_template_directory_uri() . '/assets/' . $manifest[$entry]['file'];
    }

    error_log("Asset not found in manifest.json: " . $entry);
    return '';
}

Фаза 2: Настройка бэкенда (WordPress)

2.1. Модульная структура functions.php: Чтобы избежать превращения functions.php в один огромный, неподдерживаемый файл, мы изначально спроектируем его модульным. Основной functions.php будет служить точкой входа, которая подключает (require) другие PHP-файлы из специальной директории (например, /inc или /functions). Логика будет разделена по файлам в соответствии с ее назначением: inc/enqueue-assets.php (для подключения стилей и скриптов), inc/theme-support.php (для add_theme_support), inc/custom-post-types.php и т.д.
Фаза 3: Интеграция и DX

3.1. Продвинутое подключение JS-модулей в WordPress: Стандартный wp_enqueue_script() не добавляет атрибут type="module". Поскольку functions.php будет модульным, усложнение не будет критичным. Поэтому мы реализуем продвинутый способ: будем использовать PHP-фильтр script_loader_tag для добавления type="module" к нашему скрипту и подключать его в <head>. Это обеспечит максимально быструю загрузку ресурсов и будет соответствовать современным стандартам.

Наш Окончательный Список Кандидатов в Макросы (Версия 3.0)
Основываясь на этом финальном, отточенном правиле, вот наш список.
1. Элементы UI-кита (Атомы) — ОДОБРЕНО:
icon() (уже есть)
input() (уже есть)
button()
Другие элементы форм: textarea(), checkbox() и т.д.
Причина: Это самодостаточные элементы, которые сокращают громоздкий HTML до одной строки.
2. Структурные Компоненты (Молекулы) — ОДОБРЕНО:
section() (обертка для секций)
Причина: Оборачивает уникальный контент в стандартный, повторяющийся "каркас".
3. Вспомогательные Компоненты (Организмы) — ОДОБРЕНО с оговоркой:
breadcrumbs()
Причина: Инкапсулирует сложную логику (проверка последнего элемента). Будет использоваться, только если решение через плагин окажется сложнее или хуже.
4. Компоненты для Циклов — ОТКЛОНЕНО:
card()
Причина: Является лишней абстракцией. Разметка карточки будет находиться либо напрямую в цикле, либо в подключаемом partial-файле ({% include %}), который вызывается из цикла.

// /scripts/compress-images.js

import tinify from "tinify";
import dotenv from "dotenv";
import { glob } from "glob";
import { promisify } from "util";
import path from "path";
import fs from "fs";
import ora from "ora";
import chalk from "chalk";

// --- Конфигурация ---
// Загружаем переменные окружения из /frontend/.env
dotenv.config({ path: path.resolve(process.cwd(), "frontend", ".env") });

const SOURCE_DIR = "frontend/src/assets/images"; // Папка с исходными изображениями
const OUTPUT_DIR = "frontend/src/assets/images-tiny"; // Папка для сжатых изображений
const CACHE_FILE = "frontend/.tinypng-cache"; // Файл для кеширования, чтобы не сжимать повторно

const API_KEYS = (process.env.TINYPNG_API_KEYS || "")
  .split(",")
  .filter(Boolean);
// --- Конец Конфигурации ---

// Промисифицируем функции для удобной работы с async/await
const stat = promisify(fs.stat);
const mkdir = promisify(fs.mkdir);
const writeFile = promisify(fs.writeFile);
const readFile = promisify(fs.readFile);

/**
 * Загружает кеш сжатых файлов из JSON-файла.
 * @returns {Promise<Object>} Объект с кешем.
 */
async function loadCache() {
  try {
    const cacheData = await readFile(CACHE_FILE, "utf-8");
    return JSON.parse(cacheData);
  } catch (error) {
    // Если файл не найден или пуст, возвращаем пустой объект
    return {};
  }
}

/**
 * Сохраняет обновленный кеш в JSON-файл.
 * @param {Object} cache Объект с кешем.
 */
async function saveCache(cache) {
  await writeFile(CACHE_FILE, JSON.stringify(cache, null, 2));
}

/**
 * Проверяет API ключ и устанавливает его, если он валиден.
 * @returns {Promise<boolean>} true, если валидный ключ найден и установлен, иначе false.
 */
async function validateAndSetApiKey() {
  const spinner = ora("Проверяю API ключи...").start();
  for (const key of API_KEYS) {
    try {
      tinify.key = key.trim();
      await promisify(tinify.validate)();
      spinner.succeed(chalk.green("Рабочий API ключ найден и установлен."));
      return true;
    } catch (err) {
      // Игнорируем ошибку и пробуем следующий ключ
    }
  }
  spinner.warn(
    chalk.yellow(
      "Предупреждение: ни один из API ключей не прошёл проверку (отозваны или нет сети).",
    ),
  );
  return false;
}

/**
 * Главная функция для сжатия изображений.
 */
async function compressImages() {
  console.log(chalk.cyan("--- Запуск скрипта сжатия изображений ---"));

  if (API_KEYS.length === 0) {
    console.error(
      chalk.red(
        "Ошибка: Не найдены API ключи в переменной окружения TINYPNG_API_KEYS.",
      ),
    );
    return;
  }

  const isValidKey = await validateAndSetApiKey();
  if (!isValidKey) {
    // Сжатие — best-effort оптимизация: если ключи не прошли проверку
    // (отозваны, нет сети и т.д.), НЕ прерываем сборку, а пропускаем шаг.
    console.warn(
      chalk.yellow(
        "⚠️ Сжатие изображений пропущено (нет рабочего API ключа). Сборка продолжается.",
      ),
    );
    return;
  }

  const spinner = ora("Идет поиск и обработка изображений...").start();
  const imagePaths = await glob(`${SOURCE_DIR}/**/*.{png,jpg,jpeg}`);
  const cache = await loadCache();
  let compressedCount = 0;
  let skippedCount = 0;

  if (!fs.existsSync(OUTPUT_DIR)) {
    await mkdir(OUTPUT_DIR, { recursive: true });
  }

  for (const imagePath of imagePaths) {
    try {
      const stats = await stat(imagePath);
      const fileMtime = stats.mtime.getTime();

      // Проверяем, есть ли файл в кеше и не изменился ли он
      if (cache[imagePath] && cache[imagePath] === fileMtime) {
        skippedCount++;
        continue; // Пропускаем файл, если он не изменился
      }

      spinner.text = `Сжимаю: ${chalk.yellow(path.basename(imagePath))}`;
      const source = tinify.fromFile(imagePath);
      const outputPath = path.join(OUTPUT_DIR, path.basename(imagePath));
      await promisify(source.toFile).call(source, outputPath);

      // Обновляем кеш с новой датой модификации файла
      cache[imagePath] = fileMtime;
      compressedCount++;
    } catch (err) {
      spinner.fail(chalk.red(`Не удалось сжать ${path.basename(imagePath)}.`));
      console.error(err);
    }
  }

  await saveCache(cache);

  const totalProcessed = compressedCount + skippedCount;
  if (totalProcessed === 0) {
    spinner.info(
      chalk.yellow(
        `Не найдено изображений для обработки в папке ${SOURCE_DIR}.`,
      ),
    );
  } else {
    spinner.succeed(chalk.green("Обработка изображений завершена."));
  }

  console.log("---");
  console.log(
    `✅ Сжато новых/измененных файлов: ${chalk.green(compressedCount)}`,
  );
  console.log(`⏩ Пропущено (без изменений): ${chalk.yellow(skippedCount)}`);
  console.log(chalk.cyan("--- Скрипт завершил работу ---"));
}

/*!
 * =================================================================================================
 * build-target.js
 * =================================================================================================
 *
 * Общая утилита для post-build скриптов: определяет ФИНАЛЬНЫЙ каталог сборки.
 *
 * Режим (target) определяется в порядке приоритета:
 *   1. Переменная окружения  BUILD_TARGET=static|wordpress
 *   2. Файл project.config.json в корне проекта:
 *        { "build": { "target": "wordpress" } }
 *   3. По умолчанию — "wordpress" (bridge-режим: boilerplate заточен под тему WP).
 *
 * Каталоги:
 *   static     -> dist/                                 (статический лендинг)
 *   wordpress  -> backend/wp-content/themes/my-theme/  (тема WordPress)
 *
 * Использование:
 *   import { stageDir, resolveBuildTarget } from "./build-target.js";
 *
 * =================================================================================================
 */

import { readFileSync } from "node:fs";
import path from "node:path";

export const rootDir = path.resolve(import.meta.dirname, "..");
// Промежуточная папка, куда Vite пишет сборку (см. build.outDir в vite.config.js).
export const stageDir = path.join(rootDir, "build-stage");

export const TARGETS = {
  static: path.join(rootDir, "dist"),
  wordpress: path.join(rootDir, "backend", "wp-content", "themes", "my-theme"),
};

const VALID_TARGETS = Object.keys(TARGETS);

/**
 * Определяет финальный каталог сборки по конфигу проекта.
 * @returns {{ mode: string, dir: string, source: string }}
 *   mode — имя режима ("static" | "wordpress"),
 *   dir  — абсолютный путь к финальному каталогу,
 *   source — откуда взят режим (для логов).
 * @throws {Error} Если target неизвестен.
 */
export function resolveBuildTarget() {
  const envTarget = (process.env.BUILD_TARGET || "").trim().toLowerCase();
  if (envTarget) {
    if (!VALID_TARGETS.includes(envTarget)) {
      throw new Error(
        `Неизвестный BUILD_TARGET: "${envTarget}" (доступно: ${VALID_TARGETS.join(", ")}).`,
      );
    }
    return { mode: envTarget, dir: TARGETS[envTarget], source: "BUILD_TARGET" };
  }

  try {
    const config = JSON.parse(
      readFileSync(path.join(rootDir, "project.config.json"), "utf-8"),
    );
    const fileTarget = (config?.build?.target || "").trim().toLowerCase();
    if (fileTarget) {
      if (!VALID_TARGETS.includes(fileTarget)) {
        throw new Error(
          `Неизвестный build.target: "${fileTarget}" в project.config.json (доступно: ${VALID_TARGETS.join(", ")}).`,
        );
      }
      return {
        mode: fileTarget,
        dir: TARGETS[fileTarget],
        source: "project.config.json",
      };
    }
  } catch (error) {
    // Файла нет — это нормально, используем значение по умолчанию.
    // Любые другие ошибки (в т.ч. невалидный target) пробрасываем.
    if (error?.code !== "ENOENT") throw error;
  }

  return { mode: "wordpress", dir: TARGETS.wordpress, source: "по умолчанию" };
}

/**
 * Главная функция для оптимизации SVG.
 */
async function optimizeSvgImages() {
  console.log(chalk.cyan("--- Запуск скрипта оптимизации цветных SVG ---"));

  const spinner = ora("Идет поиск и обработка SVG...").start();
  const filePaths = await glob(`${SOURCE_DIR}/**/*.svg`);

  if (filePaths.length === 0) {
    spinner.info(
      chalk.yellow(`Не найдено SVG для обработки в папке ${SOURCE_DIR}.`),
    );
    console.log(chalk.cyan("--- Скрипт завершил работу ---"));
    return;
  }

  const cache = await loadCache();
  let processedCount = 0;
  let skippedCount = 0;

  // Убедимся, что папка для результатов существует
  await fs.mkdir(OUTPUT_DIR, { recursive: true });

  for (const filePath of filePaths) {
    try {
      const stats = await fs.stat(filePath);
      const fileMtime = stats.mtime.getTime();

      // Проверяем кеш: если время модификации файла не изменилось, пропускаем его
      if (cache[filePath] && cache[filePath] === fileMtime) {
        skippedCount++;
        continue;
      }

      spinner.text = `Оптимизирую: ${chalk.yellow(path.basename(filePath))}`;

      const fileContent = await fs.readFile(filePath, "utf-8");
      const result = optimize(fileContent, { path: filePath, ...svgoConfig });

      const outputPath = path.join(OUTPUT_DIR, path.basename(filePath));
      await fs.writeFile(outputPath, result.data);

      // Обновляем кеш для обработанного файла
      cache[filePath] = fileMtime;
      processedCount++;
    } catch (err) {
      spinner.fail(
        chalk.red(`Не удалось обработать ${path.basename(filePath)}.`),
      );
      console.error(err);
    }
  }

  await saveCache(cache);

  spinner.succeed(chalk.green("Обработка SVG завершена."));
  console.log("---");
  console.log(
    `✅ Оптимизировано новых/измененных файлов: ${chalk.green(processedCount)}`,
  );
  console.log(`⏩ Пропущено (без изменений): ${chalk.yellow(skippedCount)}`);
  console.log(chalk.cyan("--- Скрипт завершил работу ---"));
}

import favicons from "favicons";
import { mkdir, writeFile, rm, readFile } from "node:fs/promises";
import { existsSync } from "node:fs";
import path from "node:path";
import chalk from "chalk";

const SOURCE = path.resolve(

  "..",
  "frontend",
  "public",
  "favicon.svg",

// Промежуточная папка сборки (см. build.outDir в vite.config.js).

// Все фавикон-ассеты — в отдельной подпапке, корень сборки остаётся чистым.
const OUTPUT_DIR = path.join(STAGE_DIR, "favicons");

// Конфигурация генератора. path: "" — относительные пути в site.webmanifest,
// чтобы комплект корректно работал из подкаталога темы WordPress
// (/wp-content/themes/my-theme/), а не только с корня домена.
const faviconConfig = {

  appName: "Vite Bridge Boilerplate",
  appShortName: "ViteApp",
  appDescription: "My Awesome App description",
  lang: "ru",
  background: "#ffffff",
  theme_color: "#3b4b66",
  display: "standalone",
  orientation: "any",
  start_url: ".",
  scope: ".",
  icons: {

    android: { background: "#3b4b66" }, // android-chrome-192/512
    appleIcon: true, // apple-touch-icon.png (180x180)
    appleStartup: false,
    windows: true, // browserconfig.xml + mstile-150x150.png
    coast: false,
    firefox: false,
    yandex: false,
  },
};

async function generateFavicons() {
  console.log(chalk.cyan("--- Генерация фавикон-комплекта ---"));

  if (!existsSync(SOURCE)) {
    console.error(
      chalk.red(`❌ Исходный SVG-фавикон не найден: ${SOURCE}`),
    );
    process.exit(1);
  }
  if (!existsSync(STAGE_DIR)) {
    console.error(
      chalk.red(
        `❌ Папка build-stage не найдена: ${STAGE_DIR}. Сначала выполните vite build.`,
      ),
    );
    process.exit(1);
  }

  const { images, files, html } = await favicons(SOURCE, faviconConfig);

  await mkdir(OUTPUT_DIR, { recursive: true });

  const written = [];
  for (const entry of [...images, ...files]) {
    // favicons v7 называет webmanifest файлом manifest.webmanifest, но по
    // конвенции (и по заданию) нужен site.webmanifest — переименовываем.
    const name =
      entry.name === "manifest.webmanifest" ? "site.webmanifest" : entry.name;
    await writeFile(path.join(OUTPUT_DIR, name), entry.contents);
    written.push(name);
  }

  // Кладём копию исходного SVG в favicons/ — на неё ссылается
  // <link rel="icon" type="image/svg+xml" href="favicons/favicon.svg">.
  await writeFile(
    path.join(OUTPUT_DIR, "favicon.svg"),
    await readFile(SOURCE),
  );
  written.push("favicon.svg");

  // Vite копирует frontend/public/* в корень build-stage/ (publicDir).
  // Исходник favicon.svg нам в корне НЕ нужен — все фавикон-ассеты живут в
  // favicons/. Удаляем корневую копию, чтобы корень сборки оставался чистым.
  const stageRootFavicon = path.join(STAGE_DIR, "favicon.svg");
  if (existsSync(stageRootFavicon)) {
    await rm(stageRootFavicon, { force: true });
  }

  console.log(chalk.gray(`  Сгенерировано файлов: ${chalk.yellow(written.length)}`));
  for (const name of written.sort()) {
    console.log(chalk.gray(`  ✓ ${name}`));
  }

  // Показываем количество тегов для <head> (сами теги инжектит vite-html-asset-inject).
  console.log(
    chalk.green(`✅ Фавикон-комплект готов: ${chalk.yellow(written.length)} файлов в ${OUTPUT_DIR}`),
  );
  console.log(chalk.gray(`  (тегов для <head>: ${html.length})`));
}

generateFavicons().catch((error) => {
  console.error(chalk.red("❌ Ошибка генерации фавиконов:"));
  console.error(error);
  process.exit(1);
});

=== FILE: scripts/plugins/vite-html-asset-inject.js ===
/*!
 * =================================================================================================
 * scripts/plugins/vite-html-asset-inject.js
 * =================================================================================================
 * Кастомный build-only Vite-плагин: инжекция собранных ассетов в финальный HTML.
 *
 * vite-plugin-njk-frontmatter отдаёт страницы как "сырые" HTML-ассеты
 * (this.emitFile), минуя transformIndexHtml. Поэтому вручную:
 *  1) убираем dev-скрипт Vite HMR client (на случай, если он останется в HTML);
 *  2) заменяем dev-ссылку на /src/js/app.js реальным бандлом;
 *  3) подключаем собранный CSS в <head>.
 *
 * Плагин регистрируется ПОСЛЕ nunjucks-плагина (см. vite.config.js), поэтому
 * generateBundle отработает после эмиссии HTML-ассетов.
 */

import path from "node:path";
import fs from "node:fs";
import { createHash } from "node:crypto";

/**
 * Помощник: реврайтинг ссылок на исходные ассеты (/src/...) в собранные.
 * njk-плагин эмитит HTML через emitFile, минуя transformIndexHtml, поэтому
 * Vite сам НЕ переписывает в нём ссылки на картинки — иначе в продакшн-HTML
 * попали бы "сырые" пути вида /src/assets/.... Здесь мы хешируем файл,
 * эмитим его как img/[name].[hash][extname] и подставляем относительный путь.
 *
 * @param {object}   ctx
 * @param {string}   ctx.html            Исходный HTML-код страницы
 * @param {string}   ctx.sourceRoot      Папка с исходниками (root Vite) — от неё резолвим /src/... пути
 * @param {(opts: object) => void} ctx.emitFile  Rollup emitFile (обёртка this.emitFile)
 * @param {Set<string>}    ctx.emittedAssetNames  Имена уже эмитированных ассетов (по страницам)
 * @param {Map<string, Buffer>} ctx.assetCache    Кеш содержимого по абсолютному пути
 * @returns {string} HTML с переписанными ссылками на ассеты
 */
function rewriteSourceAssetRefs({
  html,
  sourceRoot,
  emitFile,
  emittedAssetNames,
  assetCache,
}) {
  // Глобальный матчинг ЛЮБОГО пути /src/... независимо от аттрибута:
  // src, srcset (несколько URL через запятую), data-src, href,
  // inline style="background:url(...)" и т.п.
  return html.replace(/\/src\/[^"'\s,)]+/g, (url, offset, source) => {
    // Пропускаем /src/, являющийся ЧАСТЬЮ внешнего URL
    // (https://host/src/... или //host/src/...): реврайтить можно только
    // пути, начинающиеся с корня Vite.
    const before = offset > 0 ? source[offset - 1] : "";
    if (before === ":" || (before === "/" && source[offset - 2] === "/")) {
      return url;
    }
    // Не превращаем dev-скрипт /src/js/app.js в картинку: он заменяется
    // отдельным шагом ниже. Если он досюда дошёл — шаг замены не сработал,
    // и лучше оставить ссылку как есть (с предупреждением), чем
    // хешировать JS как img/....
    if (/\.(?:js|css)(?:[?#]|$)/i.test(url)) {
      console.warn(
        `[vite-html-asset-inject] Обнаружена dev-ссылка на исходник "${url}" — проверьте замену app.js в _default.njk.`,
      );
      return url;
    }
    // Отбрасываем query-строку/фрагмент (?v=2, #hash)
    const cleanUrl = url.split(/[?#]/, 1)[0];
    // URL /src/... резолвится от корня Vite (frontend/), поэтому убираем
    // только ведущий слеш: /src/assets/x.jpg -> frontend/src/assets/x.jpg
    const absPath = path.resolve(sourceRoot, cleanUrl.slice(1));
    if (!fs.existsSync(absPath) || !fs.statSync(absPath).isFile()) {
      // Громко предупреждаем (как и в остальных guard-ах плагина), чтобы
      // битая ссылка на ассет не уехала в прод молча.
      console.warn(
        `[vite-html-asset-inject] Не удалось собрать ассет "${url}" — файл не найден: ${absPath}. Ссылка останется как есть.`,
      );
      return url;
    }
    const ext = path.extname(absPath);
    const base = path.basename(absPath, ext);
    let content = assetCache.get(absPath);
    if (content === undefined) {
      content = fs.readFileSync(absPath);
      assetCache.set(absPath, content);
    }
    const hash = createHash("sha256").update(content).digest("hex").slice(0, 8);
    const fileName = `img/${base}.${hash}${ext}`;
    if (!emittedAssetNames.has(fileName)) {
      emittedAssetNames.add(fileName);
      emitFile({ type: "asset", fileName, source: content });
    }
    return `./${fileName}`;
  });
}

/**
 * Фабрика build-only плагина инжекции собранных ассетов в HTML.
 *
 * @param {object}  options
 * @param {string}  options.sourceRoot  Корень Vite (папка frontend/) — от него
 *                                      резолвятся /src/... пути в HTML.
 * @returns {import('vite').Plugin}
 */
export function htmlAssetInjectPlugin({ sourceRoot }) {
  return {
    name: "vite-html-asset-inject",
    generateBundle(_options, bundle) {
      // Помощник: реврайтинг ссылок на исходные ассеты (/src/...) в собранные.
      const emittedAssetNames = new Set();
      // Кеш содержимого по абсолютному пути: один и тот же файл читается
      // один раз, даже если на него ссылаются несколько страниц.
      const assetCache = new Map();
      const rewrite = (html) =>
        rewriteSourceAssetRefs({
          html,
          sourceRoot,
          emitFile: (opts) => this.emitFile(opts),
          emittedAssetNames,
          assetCache,
        });

      // Чанк, собранный из frontend/src/js/app.js
      const appChunk = Object.values(bundle).find(
        (out) =>
          out.type === "chunk" &&
          out.facadeModuleId &&
          out.facadeModuleId.replace(/\\/g, "/").endsWith("/frontend/src/js/app.js"),
      );

      // Все собранные CSS-файлы
      const cssFiles = Object.values(bundle)
        .filter((out) => out.type === "asset" && /\.css$/.test(out.fileName))
        .map((out) => out.fileName);

      // Защита от "тихой" потери стилей: если в сборке не оказалось ни одного
      // CSS-файла (например, удалён импорт '../scss/app.scss' из app.js),
      // громко предупреждаем, а не отдаём страницы без стилей.
      if (cssFiles.length === 0) {
        console.warn(
          "[vite-html-asset-inject] В сборке не найдено CSS-файлов — проверьте импорт стилей в frontend/src/js/app.js.",
        );
      }

      for (const [fileName, out] of Object.entries(bundle)) {
        if (out.type !== "asset" || !fileName.endsWith(".html")) continue;
        if (typeof out.source !== "string") continue;

        let html = out.source;

        // 1. Dev-only скрипт HMR-клиента
        html = html.replace(
          /<script type="module" src="http:\/\/localhost:5173\/@vite\/client"><\/script>/gi,
          "",
        );

        // 2. Dev-ссылка на исходник app.js -> собранный чанк
        //    (относительный путь, т.к. base: './'). Регэксп устойчив к
        //    форматированию (Prettier и т.п.): не требует точного совпадения
        //    всей строки, а лишь type="module" + src="/src/js/app.js".
        if (appChunk) {
          const devScriptRe =
            /<script\s+type="module"\s+src="\/src\/js\/app\.js"\s*><\/script>/i;
          if (devScriptRe.test(html)) {
            html = html.replace(
              devScriptRe,
              `<script type="module" crossorigin src="./${appChunk.fileName}"></script>`,
            );
          } else {
            // Лучше громко упасть, чем молча отдать dev-URL в продакшн-HTML
            console.warn(
              `[vite-html-asset-inject] ${fileName}: не найдена dev-ссылка на app.js — проверьте макет (_default.njk).`,
            );
          }
        } else {
          console.warn(
            "[vite-html-asset-inject] Не найден чанк приложения (frontend/src/js/app.js) — проверьте rollupOptions.input.",
          );
        }

        // 3. Подключение фавикон-комплекта и собранных CSS в <head>
        //    (относительные пути, т.к. base: './').
        //    Фавикон-комплект (favicon.ico, png-иконки, site.webmanifest,
        //    browserconfig.xml) генерируется scripts/generate-favicons.js в
        //    build-stage/favicons/ ПОСЛЕ `vite build` — теги ссылаются на
        //    детерминированные имена файлов из этого набора (все — внутри
        //    favicons/, корень сборки остаётся чистым).
        //    ВАЖНО: этот список должен оставаться синхронным с icons-конфигом
        //    в scripts/generate-favicons.js (favicons/android/appleIcon/windows).
        const faviconTags = [
          `<link rel="icon" type="image/svg+xml" href="favicons/favicon.svg">`,
          `<link rel="icon" type="image/png" sizes="32x32" href="favicons/favicon-32x32.png">`,
          `<link rel="icon" type="image/png" sizes="16x16" href="favicons/favicon-16x16.png">`,
          `<link rel="shortcut icon" href="favicons/favicon.ico">`,
          `<link rel="apple-touch-icon" sizes="180x180" href="favicons/apple-touch-icon.png">`,
          `<link rel="manifest" href="favicons/site.webmanifest">`,
          `<meta name="msapplication-TileColor" content="#3b4b66">`,
          `<meta name="theme-color" content="#3b4b66">`,
        ].map((tag) => `    ${tag}`);
        const cssLinks = cssFiles.map(
          (file) => `    <link rel="stylesheet" href="./${file}">`,
        );
        const headExtras = [...faviconTags, ...cssLinks];
        if (headExtras.length > 0) {
          html = html.replace(
            "</head>",
            `${headExtras.join("\n")}\n  </head>`,
          );
        }

        // 4. Реврайтинг исходных путей ассетов (/src/...) на собранные.
        //    Выполняется ПОСЛЕ замены dev-скрипта app.js, чтобы не зацепить
        //    ссылку <script src="/src/js/app.js">.
        html = rewrite(html);

        out.source = html;
      }
    },
  };
}

/*!

 *
 * Вспомогательный скрипт для пакетной офлайн-конвертации изображений
 * в современные форматы .webp и .avif.
 * Работает как локальный аналог сторонних онлайн-сервисов.
 *

import sharp from "sharp";
import { glob } from "glob";
import path from "path";
import fs from "fs/promises";
import ora from "ora";
import chalk from "chalk";

// --- Конфигурация ---
const SOURCE_DIR = "frontend/src/assets/images-convert/source"; // !Папка, куда вы закидываете исходники
const OUTPUT_DIR = "frontend/src/assets/images-convert/result"; // !Папка, где появятся результаты

// Настройки качества для форматов. 80 - хороший баланс между качеством и размером.
const WEBP_QUALITY = 80;
const AVIF_QUALITY = 75; // AVIF обычно требует чуть меньшего качества для того же визуала

/**
 * Главная функция для конвертации изображений.
 */
async function convertImages() {
  console.log(chalk.cyan("--- Запуск скрипта конвертации изображений ---"));

  const spinner = ora("Идет поиск изображений...").start();

  // Убедимся, что папки существуют
  await fs.mkdir(SOURCE_DIR, { recursive: true });
  await fs.mkdir(OUTPUT_DIR, { recursive: true });

  const filePaths = await glob(`${SOURCE_DIR}/**/*.{png,jpg,jpeg}`);

  if (filePaths.length === 0) {
    spinner.warn(
      chalk.yellow(
        `Не найдено изображений для конвертации в папке ${SOURCE_DIR}.`,
      ),
    );
    console.log(
      chalk.yellow(
        `Пожалуйста, поместите файлы .jpg или .png в эту директорию.`,
      ),
    );
    console.log(chalk.cyan("--- Скрипт завершил работу ---"));
    return;
  }

  let convertedCount = 0;

  for (const filePath of filePaths) {
    const fileName = path.basename(filePath);
    const fileBaseName = path.parse(fileName).name; // Имя файла без расширения
    spinner.text = `Конвертирую: ${chalk.yellow(fileName)}`;

    try {
      const image = sharp(filePath);

      // Конвертация в WebP
      await image
        .webp({ quality: WEBP_QUALITY })
        .toFile(path.join(OUTPUT_DIR, `${fileBaseName}.webp`));

      // Конвертация в AVIF
      await image
        .avif({ quality: AVIF_QUALITY })
        .toFile(path.join(OUTPUT_DIR, `${fileBaseName}.avif`));

      convertedCount++;
    } catch (err) {
      spinner.fail(chalk.red(`Не удалось конвертировать ${fileName}.`));
      console.error(err);
    }
  }

  spinner.succeed(chalk.green("Конвертация изображений завершена."));
  console.log("---");
  console.log(
    `✅ Успешно конвертировано файлов: ${chalk.green(convertedCount)}`,
  );
  console.log(`📂 Результаты сохранены в папку: ${chalk.blue(OUTPUT_DIR)}`);
  console.log(chalk.cyan("--- Скрипт завершил работу ---"));
}

/*!
 * =================================================================================================
 * distribute.js
 * =================================================================================================
 *
 * Пост-обработка сборки: распределяет содержимое промежуточной папки
 * build-stage/ (куда Vite пишет свой вывод, см. build.outDir в vite.config.js)
 * в ФИНАЛЬНЫЙ каталог в зависимости от режима проекта:
 *
 *   static     -> build-stage/ -> dist/                                (статический лендинг)
 *   wordpress  -> build-stage/ -> backend/wp-content/themes/my-theme/  (тема WordPress)
 *
 * Режим определяется через scripts/build-target.js:
 * BUILD_TARGET (env) > project.config.json "build.target" > "wordpress".
 *
 * Папка назначения НЕ вычищается целиком: удаляются только записи, созданные
 * сборкой (см. MANAGED_DIRS / MANAGED_FILE_PATTERNS), чтобы не задеть
 * backend-файлы (style.css, functions.php, .gitkeep, кастомные папки и т.п.).
 * Затем содержимое build-stage/ копируется с перезаписью.
 *
 * Использование: `node scripts/distribute.js` (автоматически запускается
 * после `vite build` в скрипте `pnpm build`, см. package.json).
 *
 * =================================================================================================
 */

import { existsSync } from "node:fs";
import { readdir, rm, mkdir, cp } from "node:fs/promises";
import path from "node:path";
import chalk from "chalk";

import { stageDir, resolveBuildTarget } from "./build-target.js";

// Директории верхнего уровня, полностью управляемые сборкой.
// favicons/ — весь фавикон-комплект (scripts/generate-favicons.js).
const MANAGED_DIRS = new Set(["js", "css", "img", "fonts", "favicons", ".vite"]);

// Файлы/паттерны верхнего уровня, создаваемые сборкой.
const MANAGED_FILE_PATTERNS = [
  /\.html$/, // собранные страницы (index.html, test-fonts.html, ...)
  /^manifest\.json$/, // PWA-манифест
  /^registerSW\.js$/, // PWA-регистрация сервис-воркера
  /^sw\.js(\.map)?$/, // Service Worker + sourcemap
  /^workbox-.*\.js(\.map)?$/, // Workbox-чанки + sourcemap
  // ВНИМАНИЕ: все фавикон-ассеты живут строго в favicons/ (managed dir).
  // Корневые фавикон-файлы больше НЕ создаются сборкой.
  /^robots\.txt$/, // public-ассеты (копируются Vite из frontend/public)
  /^stats\.html$/, // отчёт visualizer (запуск с ANALYZE=true)
];

/**
 * Проверяет, создан ли файл сборкой (по имени верхнего уровня).
 * @param {string} name Имя файла.
 * @returns {boolean}
 */
function isManagedFile(name) {
  return MANAGED_FILE_PATTERNS.some((pattern) => pattern.test(name));
}

/**
 * Удаляет устаревшие записи сборки в целевом каталоге (только managed).
 * @param {string} targetDir Абсолютный путь к целевому каталогу.
 * @returns {Promise<number>} Количество удалённых записей.
 */
async function cleanManaged(targetDir) {
  let entries;
  try {
    entries = await readdir(targetDir, { withFileTypes: true });
  } catch (error) {
    // Каталога ещё нет — чистить нечего, distribute создаст его при копировании.
    if (error?.code === "ENOENT") return 0;
    throw error;
  }

  let removedCount = 0;
  for (const entry of entries) {
    const fullPath = path.join(targetDir, entry.name);
    const isManaged = entry.isDirectory()
      ? MANAGED_DIRS.has(entry.name)
      : isManagedFile(entry.name);

    if (!isManaged) continue;

    await rm(fullPath, { recursive: true, force: true });
    removedCount += 1;
    console.log(chalk.gray(`  🗑  Удалено (устаревшее): ${entry.name}`));
  }
  return removedCount;
}

async function distribute() {
  console.log(chalk.cyan("--- Распределение сборки (scripts/distribute.js) ---"));

  const target = resolveBuildTarget();
  console.log(chalk.gray(`  Режим: ${chalk.yellow(target.mode)} (${target.source})`));
  console.log(chalk.gray(`  Из: ${stageDir}`));
  console.log(chalk.gray(`  В:  ${target.dir}`));

  if (!existsSync(stageDir)) {
    console.error(
      chalk.red(
        `❌ Папка build-stage не найдена: ${stageDir}. Сначала выполните vite build.`,
      ),
    );
    process.exit(1);
  }

  const removedCount = await cleanManaged(target.dir);

  await mkdir(target.dir, { recursive: true });
  await cp(stageDir, target.dir, { recursive: true, force: true });

  console.log(
    chalk.green(
      `✅ Сборка распределена: ${chalk.yellow(target.dir)}` +
        ` (удалено устаревших записей: ${chalk.yellow(removedCount)}).`,
    ),
  );
}

distribute().catch((error) => {
  console.error(chalk.red("❌ Ошибка распределения сборки:"));
  console.error(error);
  process.exit(1);
});

function findVideos() {
  let videos = document.querySelectorAll('.video');

  for (let i = 0; i < videos.length; i++) {
    setupVideo(videos[i]);
  }
}

function setupVideo(video) {
  let link = video.querySelector('.video__link');
  let media = video.querySelector('.video__media');
  let button = video.querySelector('.video__btn');
  let id = parseMediaURL(media);

  video.addEventListener('click', () => {
    let iframe = createIframe(id);

    link.remove();
    button.remove();
    video.appendChild(iframe);
  });

  link.removeAttribute('href');
  video.classList.add('video--enabled');
}

function parseMediaURL(media) {
  let regexp = /https:\/\/i\.ytimg\.com\/vi\/([a-zA-Z0-9_-]+)\/maxresdefault\.jpg/i;
  let url = media.src;
  let match = url.match(regexp);

  return match[1];
}

function createIframe(id) {
  let iframe = document.createElement('iframe');

  iframe.setAttribute('allowfullscreen', '');
  iframe.setAttribute('allow', 'autoplay');
  iframe.setAttribute('src', generateURL(id));
  iframe.classList.add('video__media');

  return iframe;
}

function generateURL(id) {
  let query = '?rel=0&showinfo=0&autoplay=1';

  return 'https://www.youtube.com/embed/' + id + query;
}

function scrollToTop() {

  // button scroll to top
  const backToTopButton = document.querySelector('#scroll-to-top');

  // eslint-disable-next-line no-use-before-define
  window.addEventListener('scroll', scrollFunction);

  function scrollFunction() {
    if (window.scrollY > 500) { // Show backToTopButton
      if (!backToTopButton.classList.contains('btn-entrance')) {
        backToTopButton.classList.remove('btn-exit');
        backToTopButton.classList.add('btn-entrance');
        backToTopButton.style.display = 'block';
      }
    } else { // Hide backToTopButton
      // eslint-disable-next-line no-lonely-if
      if (backToTopButton.classList.contains('btn-entrance')) {
        backToTopButton.classList.remove('btn-entrance');
        backToTopButton.classList.add('btn-exit');
        // eslint-disable-next-line func-names
        setTimeout(function () {
          backToTopButton.style.display = 'none';
        }, 250);
      }
    }
  }

  // eslint-disable-next-line no-use-before-define
  backToTopButton.addEventListener('click', smoothScrollBackToTop);

  // function backToTop() {
  //   window.scrollTo(0, 0);
  // }

  function smoothScrollBackToTop() {
    const targetPosition = 0;
    const startPosition = window.scrollY;
    const distance = targetPosition - startPosition;
    const duration = 750;
    let start = null;

    // eslint-disable-next-line no-use-before-define
    window.requestAnimationFrame(step);

    function step(timestamp) {
      if (!start) start = timestamp;
      const progress = timestamp - start;
      // eslint-disable-next-line no-use-before-define
      window.scrollTo(0, easeInOutCubic(progress, startPosition, distance, duration));
      if (progress < duration) window.requestAnimationFrame(step);
    }
  }

  function easeInOutCubic(t, b, c, d) {
    // eslint-disable-next-line no-param-reassign
    t /= d / 2;
    if (t < 1) return c / 2 * t * t * t + b;
    // eslint-disable-next-line no-param-reassign
    t -= 2;
    return c / 2 * (t * t * t + 2) + b;
  }
}

  if (!table) return;

  const tableWidth = table.scrollWidth;

export const initScrollableTables = () => {
  const tables = document.querySelectorAll('table');
  if (!tables.length) {
    return;
  }

  // 1. Оборачиваем каждую таблицу
  tables.forEach((table) => {
    // Проверяем, не была ли таблица уже обернута
    if (table.parentNode.classList.contains('big-table')) {
      return;
    }

    const wrapper = document.createElement('div');
    wrapper.className = 'big-table';

    // Вставляем обертку перед таблицей, а затем перемещаем таблицу внутрь
    table.parentNode.insertBefore(wrapper, table);
    wrapper.appendChild(table);

    // 2. Добавляем обработчик скролла для таблицы внутри обертки
    table.addEventListener('scroll', () => {
      const scrollLeft = table.scrollLeft;
      const tableWidth = table.scrollWidth;
      const innerWidth = table.clientWidth;

      const isScrolledToEnd = Math.ceil(scrollLeft + innerWidth) >= tableWidth;
      const isScrolledToStart = scrollLeft === 0;

      if (isScrolledToEnd) {
        wrapper.classList.remove('scroll-right');
      } else if (isScrolledToStart) {
        wrapper.classList.remove('scroll-left');
      } else {
        wrapper.classList.add('scroll-right');
        wrapper.classList.add('scroll-left');
      }
    });

    // 3. Первоначальное обновление состояния
    updateTableState(wrapper);
  });

  // 4. Обновляем состояние всех таблиц при ресайзе окна
  window.addEventListener('resize', () => {
    document.querySelectorAll('.big-table').forEach(updateTableState);
  });

// --- Helpers -----------------------------------------------------------------
/**
 * Функция плавного скролла с кастомной продолжительностью.
 * @param {number} endPosition - Конечная позиция скролла (в px от верха).
 * @param {number} duration - Продолжительность анимации в мс.
 */
const smoothScrollTo = (endPosition, duration) => {
  const startPosition = window.scrollY;
  const distance = endPosition - startPosition;
  let startTime = null;

  const easeInOutCubic = (t, b, c, d) => {
    t /= d / 2;
    if (t < 1) return (c / 2) * t * t * t + b;
    t -= 2;
    return (c / 2) * (t * t * t + 2) + b;
  };

  const animation = (currentTime) => {
    if (startTime === null) startTime = currentTime;
    const timeElapsed = currentTime - startTime;
    const run = easeInOutCubic(timeElapsed, startPosition, distance, duration);
    window.scrollTo(0, run);
    if (timeElapsed < duration) requestAnimationFrame(animation);
  };

  requestAnimationFrame(animation);
};

export const initScrollToTop = () => {
  // --- Constants -------------------------------------------------------------
  const button = document.querySelector('#scroll-to-top');
  const scrollThreshold = 500; // Порог в px, после которого кнопка появляется
  const animationDuration = 750; // Длительность плавного скролла в мс

  if (!button) {
    return;
  }

  // --- Handlers --------------------------------------------------------------
  const handleScroll = () => {
    if (window.scrollY > scrollThreshold) {
      if (!button.classList.contains('btn-entrance')) {
        button.classList.remove('btn-exit');
        button.classList.add('btn-entrance');
        button.style.display = 'block';
      }
    } else {
      if (button.classList.contains('btn-entrance')) {
        button.classList.remove('btn-entrance');
        button.classList.add('btn-exit');

          if (button.classList.contains('btn-exit')) {
            button.style.display = 'none';
          }
        }, 250); // Должно совпадать с длительностью анимации .btn-exit
      }
    }
  };

  const handleClick = () => {
    smoothScrollTo(0, animationDuration);
  };

  // --- Event Listeners -------------------------------------------------------
  window.addEventListener('scroll', handleScroll);
  button.addEventListener('click', handleClick);

/*!
 * =================================================================================================
 * font-tester.js
 * =================================================================================================
 *
 * Модуль для диагностики загрузки веб-шрифтов.
 * Экспортирует одну функцию initFontTester, которая находит все тестовые карточки
 * на странице и запускает для них проверку.
 *
 * Этот модуль предназначен ТОЛЬКО для режима разработки и будет исключен
 * из финальной сборки с помощью условного импорта в app.js.
 *
 * =================================================================================================
 */

/**
 * Проверяет, загружен ли конкретный шрифт.
 * Использует FontFaceSet API (document.fonts.check).
 *
 * @param {string} family - Название font-family.
 * @param {string} weight - Значение font-weight.
 * @param {string} style - Значение font-style.
 * @returns {boolean} - true, если шрифт загружен, иначе false.
 */
const isFontLoaded = (family, weight, style) => {
  // Формируем строку для проверки, например: "bold 700 16px 'Spectral SC'"
  // Размер шрифта (16px) здесь не важен, но синтаксис его требует.
  const fontCheckString = `${style} ${weight} 16px "${family}"`;

  try {
    // document.fonts.check() - это современный и надежный способ
    // проверить, доступен ли шрифт для рендеринга.
    return document.fonts.check(fontCheckString);
  } catch (e) {
    console.error("Ошибка при проверке шрифта:", e);
    return false;
  }
};

/**
 * Находит все тестовые карточки на странице и запускает для них проверку.
 * @param {HTMLElement} container - DOM-элемент, в котором находятся карточки.
 */
export const initFontTester = (container) => {
  const cards = container.querySelectorAll(".font-test-card");

  if (cards.length === 0) {
    return;
  }

  // document.fonts.ready - это промис, который выполняется,
  // когда все шрифты, указанные в CSS, завершили загрузку (или загрузка провалилась).
  // Мы ждем этого события, чтобы наши тесты были максимально точными.
  document.fonts.ready.then(() => {
    cards.forEach((card) => {
      const { family, weight, style } = card.dataset;
      const statusElement = card.querySelector("[data-status]");

      if (!family || !weight || !style || !statusElement) {
        return;
      }

      const loaded = isFontLoaded(family, weight, style);

      if (loaded) {
        statusElement.dataset.status = "success";
        statusElement.textContent = "Успешно";
      } else {
        statusElement.dataset.status = "error";
        statusElement.textContent = "Ошибка";
      }
    });
  });
};

@use "sass:map";
@use "sass:math";
@use "sass:meta";
@use "variables" as *; // Подтягиваем карту $breakpoints

// --------------------------------------------------------------------------
// Медиа-запросы (Media Queries)
// --------------------------------------------------------------------------

// Приватная функция-помощник для брейкпоинтов.
// Приводит аргумент (ключ из $breakpoints, число с единицами или без) к
// значению в px. Возвращает null, если брейкпоинт невалиден.
// ВАЖНО: @return допустим только внутри @function, поэтому вся логика
// вынесена сюда из миксинов (в миксинах @return запрещен).
@function -breakpoint-value($breakpoint) {
  @if meta.type-of($breakpoint) == "string" and map.has-key($breakpoints, $breakpoint) {
    @return map.get($breakpoints, $breakpoint);
  } @else if meta.type-of($breakpoint) == "number" and math.is-unitless($breakpoint) {
    @return $breakpoint * 1px;
  } @else if meta.type-of($breakpoint) == "number" and not math.is-unitless($breakpoint) {
    @return $breakpoint;
  } @else {
    @warn "Invalid breakpoint `#{$breakpoint}`.";
    @return null;
  }
}

@mixin breakpoint-down($breakpoint) {
  $value: -breakpoint-value($breakpoint);

  @if $value {
    @media (max-width: #{$value - 0.02px}) {
      @content;
    }
  }
}

@mixin breakpoint-up($breakpoint) {
  $value: -breakpoint-value($breakpoint);

  @if $value {
    @media (min-width: #{$value}) {
      @content;
    }
  }
}

@use "sass:math";
@use "sass:map";
@use "variables" as *; // Подтягиваем $font-size-root и $z-indices

// Конвертирует пиксели в rem.
// @use: font-size: rem(24);
// Принимает как число с единицами (rem(24px)), так и без (rem(24)).
@function rem($pixels) {
  @if math.is-unitless($pixels) {
    $pixels: $pixels * 1px;
  }
  @return math.div($pixels, $font-size-root) * 1rem;
}

// Конвертирует пиксели в em.
// @use: font-size: em(12, 24);
// Принимает числа с единицами и без.
@function em($pixels, $context: $font-size-root) {
  @if math.is-unitless($pixels) {
    $pixels: $pixels * 1px;
  }
  @if math.is-unitless($context) {
    $context: $context * 1px;
  }
  @return math.div($pixels, $context) * 1em;
}

// Получает значение z-index из карты $z-indices.
// @use: z-index: z("modal");
@function z($key) {
  @if not map.has-key($z-indices, $key) {
    @warn "Unknown z-index key: `#{$key}`.";
  }
  @return map.get($z-indices, $key);
}
